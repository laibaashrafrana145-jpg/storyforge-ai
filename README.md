# ⚔️ StoryForge AI
Build entire fictional universes with AI — powered by Groq LLM and Microsoft Foundry IQ

## 🏆 Agents League Hackathon 2026 — Creative Apps Track

## ✨ Features
- 🧙 Character Forge — Generate heroes, villains, and side characters
- 🌍 World Forge — Generate kingdoms, planets, cities, magic systems
- 📖 Plot Forge — Generate story arcs, quests, and conflicts
- 💬 Character Chat — Talk directly to your generated characters
- ✍️ Story Continuation — Continue writing from any point

## 🤖 Microsoft IQ Integration
Uses Foundry IQ to retrieve grounded knowledge from real mythology and history before generating content — reducing hallucination and making worlds feel authentic.

## 🛠️ Tech Stack
- Frontend: React + Vite
- Backend: Python + FastAPI
- AI: Groq (llama-3.3-70b) swapping to Azure OpenAI on final submission
- Knowledge Retrieval: Azure AI Search (Foundry IQ)
- Dev Tools: GitHub Copilot in VS Code

## 🤖 GitHub Copilot Usage
- Generating FastAPI route boilerplate
- Writing React component structures
- Debugging JSON parsing errors
- Suggesting prompt engineering improvements
- Auto-completing repetitive code patterns
